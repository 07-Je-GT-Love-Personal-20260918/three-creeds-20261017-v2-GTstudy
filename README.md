## 正文与来源

六份指定中文正文来自 [CCI《敬拜赞美手册》](https://ccifellowship.org/books/book-of-praise) 对应章节。用户提供2015版PDF并明确确认已获公开使用许可。译文版权归原权利人；公开保存不意味着译文重新获得开源许可。

`content/fulltexts.json` 与V2固定版本完全相同。包括三经各1单元、比利时37条、海德堡129问、多特59条正面条款及4组驳谬，共 **232单元**。指定网页及PDF未收其他版本所附的独立多特结语，不混入其他译本。这里的“原文”指指定中文译文，不是希腊或拉丁原典。

2026-10-21重新访问155个去重来源页面，全部HTTP 200；232单元逐字核对，忽略Unicode排版空白后，字词及标点差异为0。报告见 `qa/v3-source-recheck.json`。每次构建另核对正文SHA-256。原典、来源引文与原创释义分别标识。

解释依托页面列出的古代史料和改革宗官方资料。按欧陆改革宗解释，但不将16世纪信条特定解释自动倒推为所有古代作者的意图；例如“降在阴间”说明海德堡44问的解释地位。没有声称穷尽CCI全站文章。

地理图使用Natural Earth公版底图；坐标为近似定位，不是古代疆界。插图与图标为原创SVG。图解表达教义语句关系，不把几何图形当作神本体的构造。
